# Утилита обезличивания документов

Десктопное приложение на Python: заменяет слова из словаря в документах
(.docx, .txt) с учётом русской морфологии. Назначение — обезличивание
документов перед передачей в LLM. Работает полностью локально, без интернета.

## Запуск

### macOS / Linux — `./start.sh`
- двойной клик по `start.sh` в Finder или команда `./start.sh` в терминале;
- при первом запуске сам создаст виртуальное окружение `.venv`, установит
  зависимости и откроет приложение; дальше запуск мгновенный.

### Windows — `start.bat`
- двойной клик по `start.bat`; при первом запуске сам поставит зависимости
  в `.venv` и откроет приложение.

Нужен установленный Python 3.10+ (на macOS: `brew install python`,
на Windows — с python.org, с галочкой «Add Python to PATH»).

## Сборка в один файл (PyInstaller)

**Windows (.exe):**
```
pyinstaller --onefile --windowed --name obezlichivatel ^
    --collect-data pymorphy3_dicts_ru main.py
```
Результат — `dist\obezlichivatel.exe`, запускается двойным кликом.

**macOS (.app):**
```
pyinstaller --onefile --windowed --name obezlichivatel \
    --collect-data pymorphy3_dicts_ru main.py
```
Результат — `dist/obezlichivatel.app` (на Apple Silicon собирайте на Apple Silicon).

## Как пользоваться

**Обезличивание:**
1. «Выбрать файл» — .docx или .txt.
2. «Загрузить словарь» (CSV/JSON/TXT) или «Редактор словаря» — собрать вручную.
3. «Обезличить» — будет показана статистика замен и список пропущенных слов.
4. Пропущенные слова можно отметить и одним кликом добавить в словарь
   (замены подбираются автоматически) — обработка перезапустится сама.
5. «Сохранить результат» — рядом с результатом сохранится файл маппинга
   `<имя>.mapping.json`. Оригинал не изменяется.

**Обратная замена:** вкладка «Обратная замена» → выбрать обезличенный файл
+ файл маппинга → «Восстановить исходник» → сохранить.

**Словарь.** Пары «оригинал → замена», хранятся нормализованными (леммы):
«Сидоров», «Сидорова», «сидоровым» матчатся все. Редактирование — только
через GUI (таблица), форматы файлов:
- CSV (разделитель `;` или `,` — определяется автоматически),
- JSON: `{ "Иванов": "Петров", ... }` или `[[оригинал, замена], ...]`,
- TXT: одна колонка «оригинал» (замены подберутся автогенерацией).
Проект словаря сохраняется/загружается через «Сохранить/Загрузить проект»
в редакторе.

## Разработка

```
python3.13 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m pytest tests/ -v
```

Структура: `core/` (морфология, замена, словарь, docx/txt), `ui/` (GUI),
`tests/` (pytest).
